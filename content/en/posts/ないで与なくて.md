## 释义

### 「ないで」= 不做A，去做B

表示：

不做前面的动作，然后做后面的动作

{{< ja-note >}}
朝ご飯を食べないで学校へ行った。
没吃早饭就去学校了。
{{< /ja-note >}}

### 「なくて」= 因为不…… / 没有……

表示：

原因

状态

{{< ja-note >}}
お金がなくて困っています。
因为没钱而苦恼。
{{< /ja-note >}}

### 一个经典的对比

{{< ja-note >}}
ご飯を食べないで寝た。
没吃饭就睡了。
{{< /ja-note >}}

{{< ja-note >}}
ご飯がなくて寝た。
因为没有饭吃，所以睡了。
{{< /ja-note >}}

## 用法

### 请求时只能用「ないで」

比如：

{{< ja-note >}}
入らないでください。
请不要进来。
{{< /ja-note >}}

不可以说：
{{< ja-note >}}
❌ 入らなくてください
{{< /ja-note >}}

### 形容词和名词只能用「なくて」

例如：

{{< ja-note >}}
高くなくて助かった。
不贵，帮大忙了。
{{< /ja-note >}}

{{< ja-note >}}
静かじゃなくて残念だ。
不安静，很遗憾。
{{< /ja-note >}}

没有：
{{< ja-note >}}
❌ 高いないで
❌ 静かじゃないで
{{< /ja-note >}}
这种说法。

---

从以上的说明可以看出，动词既可以有「ないで」也可以有「なくて」的用法。
